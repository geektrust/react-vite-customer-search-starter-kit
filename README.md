# React Interview Project

## Getting Started

To start the development server, run these commands in your terminal:

```bash
npm install
npm run dev
```

And you can view the app preview at:
[Preview App]({URL})

## Project Structure
- `src/`: This is where you will write your React components and logic.
- `src/CustomerSearch.jsx`: The component you need to implement.
- `src/api.js`: Provided for you. `fetchCustomers()` returns a Promise that resolves to the customer list.
- `package.json`: You can add any necessary third-party dependencies here.
